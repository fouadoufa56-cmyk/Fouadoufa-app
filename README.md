# دليل المشروع

## بنية الملفات

| الملف | المسؤولية |
|---|---|
| `constants.py` | ثوابت لا تتغيّر |
| `auth.py` | **جديد** — إنشاء الحسابات، تسجيل الدخول، تشفير كلمات المرور |
| `ui_auth.py` | **جديد** — شاشة الدخول/إنشاء حساب/زر تسجيل الخروج |
| `state_keys.py` | بناء كل مفاتيح session_state (خانات الجدول) في مكان واحد |
| `applog.py` | تسجيل الأخطاء غير المتوقعة في `app_errors.log` |
| `file_lock.py` | قفل بسيط يمنع تلف ملف الحفظ عند كتابة متزامنة |
| `models.py` | منطق بيانات نقي (تطبيع القيم، بناء نص الخانة) |
| `persistence.py` | الحفظ والتحميل — **لكل مستخدم ملفه الخاص الآن** |
| `pdf_export.py` | توليد PDF |
| `ui_styles.py` | قوالب HTML/CSS قابلة لإعادة الاستخدام لخلايا الجدول |
| `ui_pages.py` / `ui_config.py` / `ui_downloads.py` | أقسام الواجهة |
| `ui_timetable.py` | الجدول التفاعلي: قوائم اختيار لكل خانة (الأيام صفوف والفترات أعمدة) مع الربط التلقائي بين الأقسام |
| `state_keys.py` | بناء مفاتيح قوائم كل خانة في مكان واحد |
| `ui_styles.py` | قوالب HTML صغيرة لخلايا الجدول |
| `app.py` | نقطة الدخول (منسّق فقط) |

## الجدول

رجعنا للطريقة الأولى: الأيام صفوف والفترات أعمدة، وكل خانة فيها قوائم اختيار
(المادة، الأستاذ، القاعة، النوع Cours/Controle/EFM، وجمع). القسم الثاني من
كل زوج (B يتبع A مثلاً) يُملأ تلقائياً من الأول، ويمكن إلغاء الربط لأي خانة
من مربع 🔗. اختيار «-- اختر القاعة --» يعني بلا قاعة.

## يوم السبت (اختياري)

بالإعدادات (⚙️ إعداد الأقسام...) فيه خيار «➕ تفعيل يوم السبت (Samedi) بالجدول». لما تفعّله:
- يضاف صف Samedi لكل الجداول (فارغ في البداية)، وتقدر تعبّيه متل باقي الأيام.
- يظهر تلقائياً بملفات PDF وExcel المصدَّرة.
- لو ألغيته بعدين، يختفي صف Samedi من الجداول (أي بيانات كانت فيه تُحذف، فانتبه قبل الإلغاء لو عندك بيانات فيه).


## نظام الحسابات المنفصلة — كيف يعمل

- عند فتح التطبيق أول مرة، تظهر شاشة «تسجيل الدخول / إنشاء حساب جديد» ولا يظهر أي جزء من الجدول قبلها.
- كل مستخدم يُنشئ اسم مستخدم وكلمة مرور خاصة به (3-20 حرفاً/رقماً للاسم، 6 أحرف على الأقل لكلمة المرور).
- بيانات كل مستخدم تُحفظ في ملفه الخاص وحده: `user_data/{اسم_المستخدم}.json`. لا أحد غيره يقدر يشوفها من داخل التطبيق.
- زر «🚪 تسجيل الخروج» بالشريط الجانبي يمسح الجلسة الحالية بالكامل.

### ترحيل بياناتك القديمة تلقائياً
عندك بيانات فعلية بملف `saved_data.json` القديم (قبل إضافة الحسابات). **أول حساب تُنشئه بعد هذا التحديث سيأخذ هذه البيانات تلقائياً** — لن تضيع. أي حساب يُنشأ بعد ذلك يبدأ بجدول فارغ (وهذا صحيح ومقصود، حتى لا يشوف حساب جديد جدول حساب آخر).

## ⚠️ تنبيهات أمنية مهمة قبل النشر

1. **لا تضع `users.json` ولا مجلد `user_data/` على مستودع GitHub عام.** أضفتهما إلى `.gitignore` الجاهز في هذا المشروع، تأكد إنه فعلاً يمنع رفعهما (`git status` يجب ألا يُظهرهما).
2. هذا نظام دخول **بسيط** يناسب فريق صغير موثوق (مدرسة، إدارة واحدة). لا يوجد فيه:
   - استرجاع لكلمة مرور منسية
   - تحقق من البريد الإلكتروني
   - حماية من محاولات الدخول المتكررة (brute-force)

   لو تحتاج تطبيقاً بمستوى أمان أعلى (موقع عام يستخدمه مئات الأشخاص)، هذا يحتاج بنية مختلفة (قاعدة بيانات + خدمة مصادقة جاهزة)، أخبرني لو وصلت لهذه المرحلة.
3. **التخزين المؤقت (ephemeral)**: لو نشرت على Streamlit Community Cloud المجانية، قد تُمسح كل الحسابات والبيانات بعد إعادة تشغيل السيرفر. لبقاء دائم، يلزم تخزين خارجي (قاعدة بيانات أو خدمة تخزين ملفات) — أخبرني لو تحتاج هذا.

## كيف تُشغّله

```bash
pip install streamlit pandas fpdf2 arabic-reshaper python-bidi streamlit-local-storage openpyxl
streamlit run app.py
```

لا تنسَ نسخ مجلد `fonts/` (وبداخله `DejaVuSans.ttf` و`DejaVuSans-Bold.ttf`) لنفس مكان `app.py`.

لا حاجة لأي مكتبة إضافية لنظام الحسابات — يعتمد فقط على مكتبات بايثون القياسية.
